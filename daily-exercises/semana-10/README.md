# Semana 10: Enterprise CI/CD, Performance Testing with k6, Resilience Engineering, and Capstone Project

## Overview

Week 10 serves as the culmination of the 90 Days of DevOps journey. Deploying applications is only the first step in a production lifecycle; software must also withstand high concurrency surges, demonstrate disaster recovery resilience, maintain automated release governance, and be documented rigorously for global engineering operations. This week focuses on performance engineering with Grafana k6, stress testing, disaster recovery backups, automated documentation, chaos resilience, and the final capstone consolidation.

---

## Technical Curriculum Breakdown

| Day | Topic | Key Concepts and Deliverables |
|---|---|---|
| Dia 64 | Performance Testing with k6 | Virtual Users (VUs), test stages, assertions (checks), SLO thresholds |
| Dia 65 | Stress, Spike, and Soak Testing | Breaking point analysis, traffic spikes, endurance testing for leaks |
| Dia 66 | Enterprise CI/CD Release Engineering | Semantic release automation, protected environments, approvals |
| Dia 67 | Disaster Recovery & Backup Automation | Point-in-time recovery, RTO/RPO benchmarks, automated restore drills |
| Dia 68 | Documentation as Code & Runbooks | Technical runbooks, API specifications, architecture documentation |
| Dia 69 | Chaos Engineering & Resilience | Fault injection, graceful degradation, circuit breaker validation |
| Dia 70 | Final Capstone Showcase | Comprehensive multi-tier DevOps portfolio capstone architecture |
